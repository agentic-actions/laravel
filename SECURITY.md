# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.9.x | Yes |

## Reporting a vulnerability

Please do not open a public issue, discussion or pull request for a security problem.

Report it privately, by email to [security@agentic-actions.com](mailto:security@agentic-actions.com) or through GitHub's private vulnerability reporting: [report it on GitHub](https://github.com/agentic-actions/laravel/security/advisories/new). Include the package version, your Laravel and PHP versions, and the smallest set of steps that shows the problem.

Fixes ship in a patch release of the supported line, together with a GitHub security advisory.

## What the package guarantees

[docs/security.md](https://github.com/agentic-actions/laravel/blob/main/docs/security.md) lists each guarantee the package makes (the class as the allowlist, token grants, tenant binding, forbidden keys, the Read guard, what a model reads) and where each one stops. A way around one of them is a vulnerability; please report it as above.
